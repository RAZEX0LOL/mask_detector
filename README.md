## 🎯 О проекте

Это приложение для обнаружения масок на лицах в режиме реального времени через веб-камеру. Проект использует современные методы компьютерного зрения и глубокого обучения для классификации лиц по признаку наличия защитной маски.

### Основные возможности

- ✅ Обнаружение лиц в реальном времени
- ✅ Классификация наличия маски с отображением уверенности
- ✅ Обработка множественных лиц одновременно
- ✅ Удобный графический интерфейс (Tkinter)
- ✅ Кроссплатформенность (Windows, Linux, macOS)
- ✅ Логирование событий
- ✅ Высокая точность (>95% на тестовой выборке)

### Компоненты системы

```
┌─────────────────────────────────────────────────────────┐
│                    GUI Layer (Tkinter)                  │
│  ┌──────────┐  ┌───────────┐  ┌──────────┐            │
│  │  Запуск  │  │ Остановка │  │  Выход   │            │
│  └──────────┘  └───────────┘  └──────────┘            │
│  ┌─────────────────────────────────────────┐           │
│  │       Video Display (800x600)           │           │
│  └─────────────────────────────────────────┘           │
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│              Controller Layer (MaskDetectionApp)        │
│  • Управление состоянием приложения                     │
│  • Обработка событий                                    │
│  • Координация между моделями и GUI                     │
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│                   Model Layer (AI)                      │
│  ┌──────────────────────┐  ┌──────────────────────┐    │
│  │   Face Detector      │  │  Mask Classifier     │    │
│  │   (SSD ResNet-10)    │  │   (MobileNetV2)      │    │
│  │   • Обнаружение лиц  │  │   • С маской         │    │
│  │   • Confidence: 0.5+ │  │   • Без маски        │    │
│  └──────────────────────┘  └──────────────────────┘    │
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│              Video Input (VideoStream)                  │
│  • Захват кадров с веб-камеры                           │
│  • Предобработка изображений                            │
└─────────────────────────────────────────────────────────┘
```

### Процесс обработки кадра

```
1. Захват кадра (VideoStream)
          ↓
2. Изменение размера (800px width)
          ↓
3. Face Detection (SSD)
   • Blob creation
   • Forward pass
   • Threshold filtering (>0.5)
          ↓
4. ROI Extraction
   • Для каждого обнаруженного лица
   • Обрезка и нормализация
          ↓
5. Mask Classification (MobileNetV2)
   • Batch prediction
   • Softmax probabilities
          ↓
6. Визуализация результатов
   • Bounding boxes
   • Labels с вероятностью
   • Цветовое кодирование
          ↓
7. Отображение в GUI
```

### Модели машинного обучения

#### 1. Face Detector: SSD (Single Shot Detector)
- **Архитектура:** ResNet-10 backbone
- **Фреймворк:** Caffe
- **Размер входа:** 300×300
- **Файлы:**
  - `deploy.prototxt` - архитектура сети
  - `res10_300x300_ssd_iter_140000.caffemodel` - веса
- **Производительность:** ~20-30 FPS на CPU

#### 2. Mask Classifier: MobileNetV2
- **Архитектура:** MobileNetV2 с Transfer Learning
- **Фреймворк:** TensorFlow/Keras
- **Размер входа:** 224×224×3
- **Классы:** [with_mask, without_mask]
- **Файл:** `mask_detector.keras`
- **Точность:** >95% на валидационной выборке

## 🎨 Паттерны проектирования

### Использованные паттерны

#### 1. **MVC (Model-View-Controller)**
- **Model:** `faceNet`, `maskNet` - нейронные сети
- **View:** GUI компоненты Tkinter
- **Controller:** Методы класса `MaskDetectionApp`

```python
class MaskDetectionApp:
    # Model
    def load_models(self): ...
    def detect_and_predict_mask(self): ...

    # View
    def create_widgets(self): ...

    # Controller
    def start_detection(self): ...
    def stop_detection(self): ...
    def update_frame(self): ...
```

#### 2. **Singleton**
- Единственный экземпляр `VideoStream`
- Гарантирует доступ только к одной камере

#### 3. **Observer**
- Автоматическое обновление GUI при изменении кадра
- Реализовано через `root.after()`

#### 4. **Builder**
- Пошаговое создание GUI в методе `create_widgets()`

#### 5. **Command**
- Инкапсуляция операций в методах-обработчиках
- `start_detection()`, `stop_detection()`, `quit_app()`

## 📚 API документация

### Класс: `MaskDetectionApp`

Главный класс приложения для обнаружения масок.

#### Методы

##### `__init__(root: tk.Tk)`
Инициализация приложения.

**Параметры:**
- `root` - корневое окно Tkinter

**Исключения:**
- `Exception` - при ошибке загрузки моделей

---

##### `create_widgets()`
Создание GUI компонентов.

**Создает:**
- Заголовок приложения
- Фрейм видеопотока
- Кнопки управления
- Строку состояния

---

##### `load_models()`
Загрузка предобученных моделей.

**Загружает:**
1. Face Detector (SSD)
2. Mask Classifier (MobileNetV2)

**Исключения:**
- `Exception` - файлы моделей не найдены

---

##### `detect_and_predict_mask(frame, faceNet, maskNet) -> (list, list)`
Обнаружение лиц и классификация масок.

**Параметры:**
- `frame` (np.ndarray) - входной кадр BGR
- `faceNet` (cv2.dnn.Net) - модель детекции лиц
- `maskNet` (keras.Model) - модель классификации

**Возвращает:**
- `locations` (list) - координаты лиц [(x1,y1,x2,y2), ...]
- `predictions` (list) - вероятности [(mask, no_mask), ...]

---

##### `start_detection()`
Запуск процесса детекции в реальном времени.

**Выполняет:**
1. Инициализирует VideoStream
2. Прогревает камеру (2 сек)
3. Запускает цикл обновления

---

##### `stop_detection()`
Остановка процесса детекции.

**Выполняет:**
1. Останавливает VideoStream
2. Освобождает ресурсы
3. Очищает GUI

---

##### `update_frame()`
Обновление кадра в реальном времени (рекурсивный вызов).

**Процесс:**
1. Захват кадра
2. Детекция лиц
3. Классификация масок
4. Визуализация
5. Планирование следующего обновления
